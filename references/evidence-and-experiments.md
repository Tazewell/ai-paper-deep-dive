# 实验与证据审查协议

## 提取实验表（优先使用论文原始 Table/Figure）

为每个主要实验抽取：任务、数据集及划分、度量（越高/越低越好）、模型规模与训练量、baseline、作者结果、差值、随机种子与方差（如有）、硬件/成本（如有）、原文定位。

- 准确区分百分点（percentage point）和相对百分比变化。
- 列出显著优于 baseline 的任务，也列出回退和没有报告的任务。
- 检查比较是否控制了 token budget、参数量、图像分辨率、训练数据量、额外标注、训练 FLOPs、解码长度、采样策略、硬件及时间预算。
- 不把表格粗体等同于统计显著性；无误差条、置信区间或多随机种子就注明。

## 证据等级

- **论文直接报告**：原文表、公式或叙述支持；同时指明 page/section/table。
- **由原文可推导**：写出推导过程与所需假设。
- **由官方代码确认**：说明对应仓库文件、commit/tag 或版本；论文若与代码冲突，保留两边。
- **个人分析/假设**：明示未被论文验证，不使用“证明”“必然”等强断言。
- **外部工作**：独立引用来源，并检查版本与发布日期。

## 结果解析

1. 哪个核心实验真正验证本文主要假设？
2. 改进是否只来自更大的训练数据/算力，而非宣称的模块？
3. 消融是否隔离了所声称的变量？有没有关键负对照？
4. 性能提升在哪里变明显、在哪里消失？
5. 是否存在 benchmark contamination、未公示训练集或选择性报告风险？
6. 如果用户打算复现，哪些超参、数据处理、检查点和代码仍未知？

输出时避免一味赞扬和一味否定。用证据区分“论文做到了什么”与“目前还不能说明什么”。
